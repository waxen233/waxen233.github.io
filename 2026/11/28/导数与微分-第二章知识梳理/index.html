导数与微分：第二章知识梳理

发表于2026-11-28|更新于2026-11-28|数学
|浏览量:

按教材第二章的目录顺序整理：导数怎么定义、怎么求、求高阶、隐函数与参数方程、最后是微分。每节末尾附一句我自己踩过的坑。

2.1 导数的概念

2.1.1 引例

两个经典模型：变速直线运动的速度、曲线上一点处的切线斜率。它们的共同结构都是函数值的增量除以自变量的增量，再让分母趋于 0。导数就是从这个结构里抽象出来的。

2.1.2 导数的定义

设 y = f(x) 在 x₀ 的某邻域内有定义，若极限

f′(x₀) = lim (Δx → 0) [f(x₀ + Δx) − f(x₀)] / Δx

存在，则称 f 在 x₀ 处可导，该极限值就是导数。等价的写法：

f′(x₀) = lim (x → x₀) [f(x) − f(x₀)] / (x − x₀)

导数是一个比值，单位是”y 的单位 / x 的单位”。常见的记法：f′(x₀)、y′|_{x=x₀}、dy/dx|_{x=x₀}。

左导数、右导数分别把 Δx → 0⁻、0⁺，两者相等才可导。分段函数在分界点必须查这一条。

2.1.3 几何意义

f′(x₀) 是曲线在点 (x₀, f(x₀)) 处切线的斜率。

  • 切线：y − f(x₀) = f′(x₀)(x − x₀)
  • 法线（f′(x₀) ≠ 0）：y − f(x₀) = −(1 / f′(x₀)) (x − x₀)

f′(x₀) = 0 时切线水平，法线竖直，写成 x = x₀。

2.1.4 可导与连续的关系

可导必连续，连续不一定可导。

y = |x| 在 x = 0 处连续，但左右导数分别是 −1 和 1，不可导；y = ∛x 在 0 处连续，导数为无穷大，也不可导。

坑：判断”可导必连续”这类命题时，反例要能说出具体函数，光背结论考试容易记反方向。

2.2 导数的求导法则

2.2.1 四则运算

(u ± v)′ = u′ ± v′
(uv)′ = u′v + uv′
(u / v)′ = (u′v − uv′) / v²　（v ≠ 0）

2.2.2 反函数的求导法则

若 x = φ(y) 单调可导且 φ′(y) ≠ 0，其反函数 y = f(x) 的导数为

f′(x) = 1 / φ′(y)　，即　dy/dx = 1 / (dx/dy)

例如 y = arcsin x 由 x = sin y 反解而来：dy/dx = 1 / cos y = 1 / √(1 − x²)。

坑：反函数求导最常见的错是忘了取倒数，直接把 dx/dy 当成答案。

2.2.3 复合函数的求导法则

设 y = f(u)，u = φ(x)，且两者都可导，则

dy/dx = dy/du · du/dx　，即　[f(φ(x))]′ = f′(φ(x)) · φ′(x)

链式法则可以一层层套下去，从最外层往里剥，每剥一层乘一个内层导数。比如 y = ln(sin 2x)：

y′ = (1 / sin 2x) · cos 2x · 2

2.2.4 导数表

函数 导数 函数 导数
C 0 x^μ μ x^(μ−1)
sin x cos x cos x −sin x
tan x sec² x cot x −csc² x
sec x sec x tan x csc x −csc x cot x
a^x a^x ln a e^x e^x
log_a x 1 / (x ln a) ln x 1 / x
arcsin x 1 / √(1 − x²) arccos x −1 / √(1 − x²)
arctan x 1 / (1 + x²) arccot x −1 / (1 + x²)

坑：(ln x)′ = 1/x 与 (a^x)′ = a^x ln a 这两个 ln 的位置极容易混——一个是”底数的自然对数在分子”，一个是”乘上去”。

2.3 高阶导数

2.3.1 概念

y′ = f′(x) 仍是 x 的函数，再对它求导就是二阶导数 y″ = d²y/dx²，依此类推。n 阶导数记 y⁽ⁿ⁾。

力学里：位移对时间的一阶导是速度，二阶导是加速度。

2.3.2 计算

常用的几条：

(e^x)⁽ⁿ⁾ = e^x
(sin x)⁽ⁿ⁾ = sin(x + nπ/2)，(cos x)⁽ⁿ⁾ = cos(x + nπ/2)
(xⁿ)⁽ⁿ⁾ = n!，(xⁿ)⁽ᵏ⁾ = 0（k > n）
(1/x)⁽ⁿ⁾ = (−1)ⁿ n! / x^(n+1)

乘积的 n 阶导用莱布尼茨公式：

(uv)⁽ⁿ⁾ = Σ(k=0..n) C(n,k) · u⁽ᵏ⁾ · v⁽ⁿ⁻ᵏ⁾

坑：(uv)″ ≠ u″v″，这是最容易顺手的错，必须走莱布尼茨或逐次求导。

2.4 隐函数与参数方程的导数

2.4.1 隐函数的导数

方程 F(x, y) = 0 确定了 y 是 x 的函数（不一定能解出来）。做法是：把 y 看成 x 的函数，方程两边同时对 x 求导，碰到 y 的项按复合函数处理，末尾乘 y′，然后解出 y′。

例：x² + y² = 25，求 y′。

两边对 x 求导：

2x + 2y · y′ = 0　⟹　y′ = −x / y

在 (3, 4) 处 y′ = −3/4。注意这里没有开方、没有正负讨论——这正是隐函数求导比”先解出 y”更省事的地方。

两点附带信息：

  • y′ 里带着 y 是正常的，它表示”用这个点的坐标表示斜率”，代值即可
  • y = 0 时公式失效（分母为 0），不是算错，而是那里切线竖直

对数求导法也常归到这里：y = u(x)^v(x) 两边取对数再求导，例如 y = x^x 得 y′ = x^x (ln x + 1)。

2.4.2 参数方程所确定的函数的导数

设 x = φ(t)，y = ψ(t)，且 φ′(t) ≠ 0：

dy/dx = ψ′(t) / φ′(t)

二阶导不能直接对上式再对 t 求一次，而要用

d²y/dx² = [ d/dt (dy/dx) ] / φ′(t)

坑：参数方程的二阶导，忘了最后再除以 x′(t)，是这一节最标准的错。

2.4.3 相关变化率

x 与 y 都由 t 决定，已知一个的速率求另一个：把关系式两边对 t 求导，代入已知量。

例：气球充气，体积 V = 4πr³/3，已知体积增长率，求半径增长率——dV/dt = 4πr² · dr/dt，解出 dr/dt。

2.5 函数的微分

2.5.1 微分的概念

若函数增量可以写成

Δy = A · Δx + o(Δx)　（A 与 Δx 无关）

则称 f 在 x₀ 处可微，A · Δx 称为微分，记作 dy。可以证明 A = f′(x₀)，于是

dy = f′(x₀) · dx　（其中 dx = Δx）

一元函数里”可微”与”可导”等价。

三个符号的分工，务必分清：

  • dx：自变量的增量，自己取，可以是 0.1、0.001、负数
  • dy：按斜率估出来的函数值增量，dy = f′(x) dx
  • f′(x)：换算率，只跟所在的点有关

坑：dx 不是”求导的结果”，f′(x) 才是那个 Result；dy 也不等于真实增量 Δy，两者差一个 o(dx)。

2.5.2 微分公式与微分法则

由 dy = f′(x) dx，导数表可以整体翻译成微分表，例如

d(sin x) = cos x dx，d(e^x) = e^x dx，d(ln x) = dx / x

法则：

d(u ± v) = du ± dv
d(uv) = u dv + v du
d(u / v) = (v du − u dv) / v²

以及一阶微分形式不变性：不论 u 是自变量还是中间变量，dy = f′(u) du 的形式都成立。这保证了复合函数的微分可以逐层算。

2.5.3 几何意义与近似计算

几何上，dy 是切线上纵坐标的增量，Δy 是曲线上的增量。曲线被切线替代的那一小段，误差就是 o(dx)。

近似公式：

f(x₀ + Δx) ≈ f(x₀) + f′(x₀) · Δx

例：求 √25.2 的近似值。取 f(x) = √x，x₀ = 25，Δx = 0.2：

f′(25) = 1 / (2√25) = 0.1
dy = 0.1 × 0.2 = 0.02
√25.2 ≈ 5 + 0.02 = 5.02

真实值 5.019960…，误差在小数点后第四位。

坑：近似计算题里，Δx 要取”离得近、又好算”的点。取 x₀ = 25 而不是 26，就是因为 √25 = 5 是整数。

总习题常见题型

  1. 用定义求导数（尤其是分段函数分界点、x = 0 处）
  2. 复合函数求导（多层嵌套、含根号与三角函数）
  3. 隐函数求导与切线方程
  4. 参数方程的一阶、二阶导数
  5. 高阶导数（含莱布尼茨公式）
  6. 相关变化率应用题
  7. 微分的近似计算与误差估计

我自己的易错清单

  • dx 当成导数结果（f′(3) = 6 不等于 dx = 6）
  • dy 与 Δy 混用
  • 隐函数对 y 的项求导时忘了乘 y′
  • 参数方程二阶导忘了再除以 x′(t)
  • (uv)″ 直接写成 u″v″
  • 反函数求导忘了取倒数
